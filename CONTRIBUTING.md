# Guia de Contribucion

¡Gracias por tu interes en contribuir a App Notas!

## ¿Como reportar un error?

1. Revisa que el error no este reportado previamente en la pestaña **Issues**.
2. Abre un nuevo **Issue** detallando los pasos para reproducir el fallo y tu navegador web.

## Lista de verificacion para Pull Requests

Antes de enviar tus cambios, confirma que cumples con lo siguiente:

- [ ] El codigo sigue la estructura limpia del proyecto.
- [ ] Has probado la funcion agregada en tu navegador.
- [ ] El mensaje del commit es claro y descriptivo.
